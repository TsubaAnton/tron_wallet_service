FastAPI микросервис для получения информации о Tron-кошельке

Технические требования: Python 3.9+, FastAPI 0.115.12+, SQLAlchemy 2.0.40+, Tronpy 0.5.0+

Перед запуском проекта необходимо:
1. Создать виртуальное окружение: python -m venv venv
2. Активировать его: 
    Linux/macOS - source venv/bin/activate
    Windows - venv\Scripts\activate
3. Установить зависимости: pip install -r requirements.txt
4. Создать файл .env в корне проекта на основе .env.sample
5. Запустить приложение: uvicorn main:app --reload

Документация доступна по адресу http://localhost:8000/docs

Для запуска тестов используйте команду: pytest

Для работы с API необходимо получить TRON API ключ.
В проекте реализована функциональность для получения информации о кошельке, такой как баланс TRX, лимиты пропускной способности и энергии.
